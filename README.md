# BREW & BEAN, Coffee Shop WebsiteA responsive coffee shop website with a working shopping cart and a filterable menu, built with plain HTML, CSS and JavaScript (no frameworks).**Live demo:** https://coffee-shoop-lake.vercel.app## Features- Menu rendered from a JavaScript data array- Category filter: All Items, Coffee, Iced Drinks- Shopping cart: add items, increase/decrease quantity, remove, live subtotal- Cart is saved in the browser with `localStorage`, so it survives a page refresh- Mobile menu (burger button), skip-to-content link and ARIA labels for accessibility- Scroll reveal animations- Fully responsive layout## Built withHTML5, CSS3, vanilla JavaScript (ES6), Google Fonts, Unsplash images## Run locally1. Download the repository (Code > Download ZIP) and unzip it.2. Open `index.html` in your browser.## What I learned- Rendering UI from data with JavaScript- Managing state (the cart) and saving it with `localStorage`- Event delegation and DOM updates- Accessibility basics## Next stepsRebuild this project in React with components and state hooks.## AuthorMohamed Abd Eldayem, front-end developer from Tanta, Egypt.LinkedIn: https://www.linkedin.com/in/mohamed-abd-eldayem-4b126a36b
